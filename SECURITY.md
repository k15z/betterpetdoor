# Security

Please report vulnerabilities privately through GitHub's **Report a vulnerability** flow instead of a public issue.

Keep your admin password, encryption secret, and configured provider values out of logs and source control. Treat a Wayzn pairing QR code as a credential. If one is exposed, remove that user in Wayzn and create a new pairing code.

Better Pet Door is an unofficial independent project. It is not affiliated with or endorsed by Wayzn.
